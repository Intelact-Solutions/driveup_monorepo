## Description

Issue: The instructors want to have a view in which they have a good overview of their entire working day, without having to scroll in the calendar.
Solution: For both day and week view, adjust calendar size in a way which allows the user to see at least 8 hours of the day in a single view. (discuss details with Admir).
Issue: Based on the feedback of the instructors, the week view will be used much more than initially anticipated. In this view, the student image is taking a too prominent position and prevents the display of other data.
Solution: Remove student image on the week view.
