## Description

Current implementation: In order to activate a category, user has to click on the + button and click on the delete icon in order to deactivate. This implementation is misleading for the user.
Implement a switcher for activation and deactivation. Turning on the switcher, will open the form and enable editing the category. Turning off the switcher will deactivated the category.
