## Description

Issue:
- Currently, it takes the user multiple steps when the user wants to add a new appointment. We would like to have a more direct and global workflow to do that.
- From a language perspective, we have a repetition of the word “new”
Solution:
- Add “Appointment” (Termin) button to global add list, at position number 1.
- Remove the repeated “Neue” in the list, so that the list looks like this:
- Termin
- Fahrschüler
- Zahlung
- Ausgabe
